# Schoolboy Keys (дополнение к SchoolBoyRunaway, Forge 1.20.1)

Что добавляет:
* 16 цветных ключей (по цветам красителей). Ключ можно положить на пол (ПКМ с ключом в руке),
  ПКМ по лежащему ключу — забрать обратно.
* «Дверь с замком» — двухблочная дверь, которой можно назначить свой ключ.

## Как пользоваться дверью
1. Поставьте дверь, возьмите любой цветной ключ.
2. **Shift + ПКМ** ключом по двери — дверь привязывается к этому ключу и запирается.
3. **ПКМ** подходящим ключом — отпереть и открыть. **Shift + ПКМ** подходящим ключом — запереть/отпереть.
4. Другой ключ (другой цвет или другой экземпляр) не подходит. Сломайте дверь, чтобы назначить ей новый ключ.

Крафт: ключ = железный слиток + краситель; дверь = железная дверь + крюк-растяжка (всё это есть и в творческом режиме).

## Как собрать .jar
Вариант 1 (проще всего, без установки программ): загрузите папку на GitHub (новый репозиторий) —
вкладка Actions → build → скачайте артефакт `schoolboykeys-jar`.

Вариант 2: JDK 17 + Gradle 8.8, затем в папке проекта: `gradle build`. Готовый файл: `build/libs/schoolboykeys-1.20.1-1.0.0.jar`.

Положите получившийся jar в папку `mods` рядом с SchoolboyMod. Мод независимый, оригинальный jar менять не нужно.
